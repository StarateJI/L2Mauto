🖥 Установка на новый ПК
Шаг 1 — Python
Установи Python 3.11

Шаг 2 — Зависимости
Открой PowerShell в папке бота:

pip install -r requirements.txt
Шаг 3 — Tesseract OCR
⚠️ ОБЯЗАТЕЛЬНО для аукциона. Без него бот не может читать статус лота («Продаётся» / «Не продано» / таймер) и будет пропускать лоты.

📥 Скачать установщик (Tesseract OCR для Windows):
Прямая ссылка: tesseract-ocr-w64-setup-5.4.0.20240606.exe

Страница всех версий: https://github.com/UB-Mannheim/tesseract/wiki

Установка:
1. Запусти tesseract-ocr-w64-setup-5.4.0.20240606.exe
2. Путь — по умолчанию: C:\Program Files\Tesseract-OCR\
3. На этапе выбора компонентов раскрой «Additional language data (download)»
   и поставь галочку на Russian (и English если нет)
4. Нажми Install
5. Перезапусти бота

Проверка: в логе после запуска должна появиться строка:
  Аук: статус лота OCR: 'продается ]'  (или другой текст статуса)

Если OCR не работает, бот пишет:
  Аук: pytesseract недоступен — НЕ ТРОГАЮ лот (безопасно)
В этом случае проверь что tesseract.exe по пути:
  C:\Program Files\Tesseract-OCR\tesseract.exe

Шаг 4 — Личные файлы
Скопируй со старого ПК в папку бота (⚠️ НЕ заливаются в репозиторий!):

Файл
Что это
tg.ini  🔑 Токен Telegram-бота
settings/       📋 Анкеты окон

Шаг 5 — Запуск
Просто запусти start.bat 🚀

⚠️ Важно знать
🔒 tg.ini, settings/, logs/ — НЕ хранятся в репозитории
💎 Алмазные (донат) награды никогда не покупаются — только за адену
👁 Окна игры не сворачивать и не перекрывать — бот должен их видеть
🖥 Аукцион работает только на фуллскрине 2560×1440
🖱 Не трогай мышь, пока бот кликает — курсор общий
🔄 Обновление
На всех ПК: запусти бота → дождись жёлтой кнопки «♿️ Доступна обнова!» → жми → бот сам скачает, поставит и перезапустится.

Бэкап старой версии автоматически сохраняется в backups/.
