🖥 Установка на новый ПК
Шаг 1 — Python
Установи Python 3.11

Шаг 2 — Зависимости
Открой PowerShell в папке бота:

pip install -r requirements.txt
Шаг 3 — Tesseract OCR
Нужен только для аукциона. Установи с путём по умолчанию:

📥 Скачать установщик → кнопка «Latest installer for Windows»

Шаг 4 — Личные файлы
Скопируй со старого ПК в папку бота (⚠️ НЕ заливаются в репозиторий!):

Файл
Что это
tg.ini	🔑 Токен Telegram-бота
settings/	📋 Анкеты окон

Шаг 5 — Запуск
Просто запусти start.bat 🚀

⚠️ Важно знать
🔒 tg.ini, settings/, logs/ — НЕ хранятся в репозитории
💎 Алмазные (донат) награды никогда не покупаются — только за адену
👁 Окна игры не сворачивать и не перекрывать — бот должен их видеть
🖥 Аукцион работает только на фуллскрине 2560×1440
🖱 Не трогай мышь, пока бот кликает — курсор общий
🔄 Обновление
На всех ПК: запусти бота → дождись жёлтой кнопки «♿️ Доступна обнова!» → жми → бот сам скачает, поставит и перезапустится.

Бэкап старой версии автоматически сохраняется в backups/.
