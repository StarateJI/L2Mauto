L2Mauto
Мой личный бот для Lineage2M (форк L2Monad с доработками).

Что добавлено/исправлено относительно оригинала
Честные ошибки запуска (тихая смерть окон побеждена)
Умное засыпание окон с подтверждением
Пачки окон не зависают на проблемных окнах
Память окон: опознание безымянных окон по позиции
Автоподгон размера окна к 400x225
Шедуля-режим: закуп через игровое расписание ("запустил и спи")
Камера-часовой Шедули с авто-перезапуском
Растянутые тайминги Buyer/Rewards (медленнее, но без багов)
Живучие расписания (окно 15 мин + догон пропущенного)
Система обновы со своего репозитория (кнопка в GUI)
Читалка цен аукциона через Tesseract OCR
Установка на новый ПК (один раз)
Установить Python 3.11
Установить зависимости: pip install -r requirements.txt
Установить Tesseract OCR (нужен только для аукциона):
Скачать установщик: https://github.com/UB-Mannheim/tesseract/wiki
Кнопка "Latest installer for Windows"
Установить с путём ПО УМОЛЧАНИЮ (C:\Program Files\Tesseract-OCR)
Скопировать в папку бота (НЕ в репозиторий!):
tg.ini — токен Telegram-бота
папку settings/ — анкеты окон
Запуск через start.bat
